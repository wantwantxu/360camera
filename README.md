# PANO 360 Pro

手机拍 VR / 全景空间采集应用（Flutter · Android / iOS）。使用真实手机相机完成多点位 360° 采集，在本机合成全景并串成可漫游的 VR 空间。

## 功能

### 空间与点位
- 新建空间时可选择住宅、公寓、商铺、办公、展馆等类型
- 空间列表展示封面、点位数、标签数与最近更新时间
- 空间详情支持重命名、删除、设置封面、逐点进入 VR 漫游
- 点位可重命名、删除；导入的全景会明确标记「方位未知」

### 24 方向引导采集
- 每个点位拍摄 8 个水平方向 + 8 个仰角 50° + 8 个俯角 50°（上下环错位 22.5°），共 24 帧
- 以进入采集时的真实指南针方向锚定 H-01，后续方向按磁北顺序推进
- 加速度计 + 磁力计融合姿态，自适应低通滤波 + 死区发布抑制画面抖动；自动锁定前需姿态稳定，锁定有 12° 进入 / 20° 退出回差与 280 ms 丢锁容差，可切换为拖拽虚拟云台手动完成
- 采集期间同时积分陀螺仪航向（按重力方向投影角速度、静止时自学习零速偏置），每帧把「罗盘融合姿态」与「陀螺预测姿态」一起交给拼接器做光度择优——陀螺只是先验，与画布不匹配时自动退回罗盘姿态
- AR 目标标记、中心准星、水平仪、剩余方向提示与拍摄进度
- 单个点位支持重拍、部分方向合成（明确提示拉伸风险）与完整合成
- 合成结果使用球体预览确认，可保存为空间点位
- 拼接输出 4096×2048，使用每帧实际拍摄姿态（亚像素平滑后的 yaw / pitch / roll）做针孔到等距柱状投影；每帧再与画布重叠区做 3 自由度（偏航 / 俯仰 / 横滚）光度配准（ZNCC 粗到细搜索，吸收室内指南针漂移与姿态误差），重叠像素按通道做增益 + 偏移最小二乘曝光补偿；陀螺预测航向作为第二候选位姿参与同一配准（候选择优，不强制采用）；低纹理处平滑融合、有纹理处窄接缝（覆盖置信度更高的一帧胜出），重叠区两侧覆盖相当时优先采用最新帧的纹理细节以避免 50/50 平均造成的细节减半与重影；输出前轻度 USM 锐化；未覆盖的极点保持暗色

### 多点位 VR 漫游
- 全景拖拽环顾、双指缩放
- 按采集顺序生成「前往 / 返回」方向热区，点击切换点位
- 底部点位缩略图条、空间示意图（左上角开关）
- 自动旋转巡航、在任意视角添加 / 删除文字标签
- 分享原始全景图片文件，便于外部查看

### 数据
- 全部数据保存在本机应用文档目录，不上传云端
- 媒体文件按空间 / 点位分目录存放，JSON 原子写入，损坏文件自动备份

## 运行

```bash
flutter pub get
flutter run
```

真实采集需要物理设备的后置相机、加速度计与磁力计；模拟器无法验证相机与传感器行为。

Android Release APK：

```bash
flutter build apk --release
# 输出: build/app/outputs/flutter-apk/app-release.apk
```

本项目 Android 构建使用 JDK 17（`compileOptions` / `kotlinOptions` 均为 17）。

## 使用流程

1. 首页新建空间，进入空间详情
2. 点击「开始采集」，允许相机权限，等待指南针读数
3. 站到点位中央，保持手机竖直，按 HUD 提示缓慢转动；对准后自动锁定拍摄
4. 24 方向完成后合成 4K（4096×2048）全景，在球体预览中确认、重拍或保存
5. 保存后可继续拍摄下一点位；移动到下一个位置时建议走 2–3 米，并让手机朝向与前进方向一致
6. 在空间详情点击封面进入 VR 漫游，通过方向热区、点位条或示意图切换点位

## 方位与空间示意说明

- 点位朝向来自采集开始时的真实磁力计读数；未读取到指南针时不允许开始采集
- 点位在示意图中的位置按「采集顺序 + 2–3 米间距 + 当前朝向」推算，仅用于表达先后与相对方向，不是实测户型，也不是 SLAM 定位
- 指南针受现场磁场影响；磁场强度超出 15–110 µT 时会在界面标注「仅供参考」，但仍会如实保存测量值
- 导入的全景没有可测量的拍摄朝向，因此不会生成方向热区，也不会伪造方位

## 数据存储

应用文档目录下 `pano_spaces/`：

- `spaces.json`：空间、点位、标签与示意图坐标（原子写入，解析失败时备份为 `.corrupt-*`）
- `media/<spaceId>/`：每个点位的全景原图与缩略图

卸载应用会清除上述数据；当前没有云端同步或账号体系。

## 权限

- 相机：采集全景，进入采集页时才初始化相机，离开采集页会释放
- 相册：导入已有全景、导出图片
- 运动传感器：指南针锚定、自动对准、水平仪与体感云台

## 结构

- `lib/app.dart` — 路由：首页 / 空间详情 / 24 方向采集 / VR 漫游
- `lib/domain/vr_space.dart` — 空间、点位、标签、顺序热区与示意坐标
- `lib/data/space_repository.dart` — 空间 JSON 与媒体文件持久化
- `lib/features/vr/` — 首页、空间详情、采集页、漫游页、示意图组件
- `lib/features/session/pano_session.dart` — 相机、传感器、24 / 14 点采集、拼接与作品库
- `lib/features/capture/stitch_projector.dart` — 4K 姿态投影 equirectangular 拼接（3 自由度光度配准、逐通道曝光补偿、低纹理平滑/纹理窄接缝、极点留空）
- `lib/features/capture/camera_frame_decoder.dart` — 相片快速解码与 EXIF 方向归一
- `lib/features/capture/widgets/camera_preview_cover.dart` — 按传感器比例裁剪填充的预览
- `lib/features/preview/pano_sphere_view.dart` — 球体预览
- `lib/core/utils/attitude_filter.dart` — 自适应姿态低通滤波
- `lib/core/utils/compass_utils.dart` / `heading_sampler.dart` — 方位融合与采样
- `lib/core/utils/gyro_heading.dart` — 陀螺航向积分（重力投影 + 零速偏置自学习），供拼接器候选择优

## 算法参考

- Szeliski, *Image Alignment and Stitching: A Tutorial*（2006）：直接法 / 光度配准、球面投影与束调整框架，本项目 3 自由度 ZNCC 配准的来源
- Brown & Lowe, *Automatic Panoramic Image Stitching using Invariant Features*（IJCV 2007）：旋转束调整 + 增益补偿 + 多频段融合，室内指南针漂移修正与曝光补偿的思路
- Burt & Adelson, *A Multiresolution Spline with Application to Image Mosaics*（1983）：多频段融合，低纹理宽过渡 / 纹理窄接缝的算法基础
- OpenCV `stitching` 模块（`ChannelsCompensator`、`GraphCutSeamFinder`、`MultiBandBlender`）：工业界接缝与曝光补偿管线参考
- Kronbii/360-spherical-stitching：手机纯旋转拍摄的开源管线，与本项目「旋转-only 采集」场景一致；其陀螺先验分支是本项目「陀螺预测航向作为拼接候选位姿」的来源
- 关于全局束调整：本项目不保留全部关键帧做离线全局优化（24 帧解码图常驻内存不可控），改为每帧投影时对已合成画布做光度配准——等价于增量式全局调整，误差不会随帧数累积放大

## 已知限制

- 本应用不做云端 3D 重建。全景由 24 帧按姿态投影近似拼接，近景视差、接缝与动态物体会产生瑕疵（已做 3 自由度光度配准、曝光补偿、窄接缝与覆盖平票的最新帧细节合成，但无法消除视差）；转动时尽量保持机位不移动可明显减轻近景错位
- 陀螺仪只作为候选先验：若陀螺存在标定误差、符号异常或与画面明显不符，拼接器会退回罗盘姿态；传感器失效时仍可切换到拖拽虚拟云台完成采集
- 相机插件不提供焦距，视场按典型主摄 80° 对角线结合照片宽高比估算；不同机型镜头视场差异会造成少量缩放/重叠误差，由局部配准部分补偿
- 为保证水平方向重叠，采集使用相机的最大分辨率（通常为 4:3）；若某机型最大分辨率仍为 16:9，水平视场会偏窄，拼接覆盖可能不足
- 点位间没有 SLAM / 深度传感器定位，示意图与点位坐标均为按采集顺序推算的示意数据，不代表实测尺寸或户型
- 方位为磁北方向，未应用磁偏角；需要真北时应按当地磁偏角换算
- 没有磁力计时无法定义拍摄起点，采集会被阻止；传感器受干扰时界面会提示并通过拖拽云台完成拍摄
- 分享的是原始全景图片文件，不是可在线交互的 VR 链接
- 所有数据仅保存在本机，卸载即清除
- 编译与单元测试已通过；相机、指南针与真机拼接效果仍需在目标物理设备上验证
